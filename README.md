# StockStream - Stock Video Downloader & Explorer

A lightweight, modern web tool that accesses premium stock video engines to search and download stock videos in **4K UHD, 1080p Full HD, and 720p HD** with 1-click downloads.

## Features
- **Multi-Source Stock Search**: Search Storyblocks, Pexels, and Pixabay all at once or individually.
- **Live Hover Preview**: Hover over any video card to immediately preview the footage smoothly.
- **Direct 1-Click 1080p Downloads**: High-speed downloads with custom resolution selector (4K UHD, 1080p Full HD, 720p HD, ProRes MOV).
- **Ratio & Sort Filters**: Filter by Landscape (16:9), Portrait (9:16), Square (1:1), and sort by Most Relevant, Trending, or Most Downloaded.
- **Modern Dark UI**: Clean creative suite design tailored for video creators.

## How to Run

### Option 1: Double-click `run.bat`
Simply double-click `run.bat` in this folder.

### Option 2: Python Command
Run the launcher in your terminal:
```bash
python start_tool.py
```
Then open your browser to [http://localhost:8000](http://localhost:8000).
